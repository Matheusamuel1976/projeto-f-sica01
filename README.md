# Qualidade da água

Projeto escolar em PHP para cadastrar amostras e comparar medições. Salva em JSON, sem banco de dados. Não comprova potabilidade.

Com PHP 8.3+ e Composer, execute na pasta do projeto:

```sh
composer install
php -S 127.0.0.1:8000
```

Abra http://127.0.0.1:8000.

Testes: `composer test`.
